# earthgateway.com
 
A personal developer portal styled as a 1990s dial-up BBS.
 
Doors lead to small tools and experiments, framed in a Matrix/ANSI
aesthetic with an animated ASCII torii gate and spinning globe.

## Structure
 
```
index.html main menu
/bbs/<tool>/ each tool, one folder per door
/resources/css shared styles
/resources/js shared scripts
/resources/img favicon
```

## Sections
 
- **Tools** — Dual Rubber Stamp, Generate Strings
- **Machine Room** — CPU simulators, framed via iframe door
- **The Lab** — Inu FSM, Mini NNET
 
## Built with
 
Plain HTML, CSS, and JavaScript. No frameworks, no build step.
Share Tech Mono, a 16-color palette, and hand-crafted ASCII art.
